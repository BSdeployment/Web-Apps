# 📚 Article Project Management System

A modern and intuitive system for managing article-based projects written in Markdown.

This project provides a clean and efficient interface for creating, organizing, and editing articles, making it ideal for writers, developers, and teams who work with structured content.

---

## ✨ Features

* 🗂️ Create and manage multiple projects
* ✍️ Write and edit articles in Markdown format
* 🔗 Add and manage links within articles
* 🖼️ Embed images easily
* 📝 Add notes and annotations
* 🎨 Clean, user-friendly interface

---

## 🛠️ Tech Stack

### Backend

* .NET 8
* ASP.NET Core Web API

### Frontend

* React.js

---

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* .NET 8 SDK
* Node.js (latest LTS recommended)
* npm or yarn

---

### 🔧 Installation

#### 1. Clone the repository

```bash
git clone https://github.com/your-repo-url.git
cd your-repo-folder
```

#### 2. Backend setup

```bash
cd backend
dotnet restore
dotnet run
```

The backend will start on a local server (typically [https://localhost:5001](https://localhost:5001)).

#### 3. Frontend setup

```bash
cd frontend
npm install
npm start
```

The frontend will run on [http://localhost:3000](http://localhost:3000).
